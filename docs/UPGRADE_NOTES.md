# 美术、运动与声音升级记录

日期：2026-10-01（Asia/Shanghai）。开发分支：`art/pixel-battlefield`。发布方式：合入 `main` 后由 GitHub Actions 部署 GitHub Pages。

## 最终内容

18 个正式位图资源全部来自 ChatGPT 内置 imagegen，原始文件和提示词保存在 `source-art/`。四张大场景保持 1536×1024 分辨率；地形为 640×640；单位为 192×192；履带四帧，炮口和扬尘四帧，爆炸与水花六帧。单位和效果保留真实 alpha，运行时不使用 SVG。

赤铁军团：宽履带、圆铸炮塔、厚短炮管、外置油桶；海战为木甲板、多座重炮和双烟囱的战列舰。

苍蓝先锋：窄型棱角装甲、长炮管、冷色灯光；海战为窄舰体、隐形舰桥、导弹单元和后部机坪的驱逐舰。

运动使用独立的位置容器、旋转容器、单位形态和特效层。坦克的移动曲线与履带循环、悬挂、扬尘同步；战舰带推进尾流。炮管从生成的坦克图集中遮罩拆出并表现后坐，炮弹为生成的位图，光照、拖尾和冲击波由运行时叠加。

首页有军团对峙插画。结算根据模式、胜方选择红方胜利、蓝方胜利或玩家失败插画。人机玩家始终是蓝方；双人模式以胜方为结算主体并显示另一方战败。

15 种音效使用可复现的原创分层合成样本，非真实录音。陆海表现分别制作。样本先读 Ogg，解码不支持时读 WAV；有压缩器、主音量、轻微音色变化、立体声位置、最多八个瞬时声音，以及独立环境循环。静音、后台和重置会取消当前声音；过期异步加载不会重新开始播放。

## 关联修复

- 原 `pnpm-workspace.yaml` 包含无效的 esbuild 配置，导致依赖安装报错，现已修复。
- 原 lint 脚本缺少配置且不检查 TypeScript，现已补充配置并启用 Hook 校验。
- 原规则文案的人机控制方与实际实现相反，现统一为玩家蓝方、电脑红方。
- 原跨整圆旋转会走长路径，现使用最近的转向角。
- 原弹道坐标和静态棋子运动表现被替换为独立、同步的表现层。
- 原一次动作可能同时摧毁两轴敌人，但只表现一个目标；现逐目标展示全部攻击。
- 重置会取消未结束的延迟和骰子流程，防止旧回合更改新局。
- 去除了固定悬浮 GitHub 标签和 SVG 图标依赖，链接保留在页面页脚。
